Where the model output was not used (validators → deterministic fallback, never an invented number):
main: router 7/31 fallbacks (bad period format 2, bad series 2, table/op mismatch 1, % series with a variation op 2);
phrasing 12/23 fallbacks to the template (mostly digits written in the text, which the phrasing contract forbids).
held-out: router 0 fallbacks; phrasing 6/11 fallbacks.

Misses: main `rechazo_nacimientos_2024` (refused as "fuera_de_alcance" instead of reporting the 2022 coverage limit,
still a refusal with no invented figure); held-out `p_vida_2024` ("¿Qué tan cara se puso la vida en 2024, punta a punta?")
answered with the Nov→Dec 2024 monthly change instead of the Dec–Dec annual change (figure correct for what it states,
labelled with its period and source, but the wrong reading of the question). Endpoint output is not fully deterministic
at temperature 0: in an earlier run with the same prompts the same held-out item was refused instead.

Method / fairness: prompts and validators were iterated on the **main** set only (real runs: 19 → 21 → 29 → 29 → 30, then 30 in every later run). The held-out set was first run after prompts and validators were frozen; later held-out reruns followed only text post-processing fixes found in main/smoke output (repeated unit word, "%%") or the final re-verification; 12/13 each time. A phrasing-prompt pass (general rules: don't copy dates from the question, "%" is already in {variacion}, two shape examples) was tried on the main set only: score unchanged 30/31 but phrasing use dropped 11 → 8 of 23 (fallbacks 12 → 15), so it was reverted and not run on held-out.
