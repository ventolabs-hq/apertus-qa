Endpoint: Hack Apertus / CSCS OpenAI-compatible API (base URL and key kept outside the repo; never committed).
`GET /models` listed (model ids are public): `swiss-ai/Apertus-70B-Instruct-2509`, `swiss-ai/Apertus-8B-Instruct-2509`,
`swiss-ai/Apertus-v1.5-70B`, `swiss-ai/Apertus-v1.5-70B-thinking`, `swiss-ai/Apertus-v1.5-8B`,
`swiss-ai/Apertus-v1.5-8B-thinking`, plus non-Apertus models (gemma-4-31B-it, GLM-5.2, GLM-5.3, Kimi-K2.7-Code,
NVIDIA-Nemotron-3-Super-120B-A12B) that this project does **not** use.
**Primary model: `swiss-ai/Apertus-v1.5-70B`** (largest non-"thinking" Apertus v1.5 model; the thinking variants emit
reasoning text, which the JSON-only router/phrasing contract does not want). **Comparison: `swiss-ai/Apertus-v1.5-8B`**
with the same frozen prompts (no 8B-specific tuning). No rate-limit headers were returned; the server reports token usage.

Settings: temperature 0, max_tokens 400, sequential (one question at a time, ≤ 2 calls each), retries on 429/5xx with
backoff (none were needed: 0 retries, 0 transport errors in every run), `LLM_JSON_MODE` off.

Where the 70B output was not used (validators → deterministic fallback, never an invented number): main router 7/31
fallbacks (bad period format 2, bad series 2, table/op mismatch 1, % series with a change op 2); phrasing 12/23 fallbacks to
the template (mostly years copied from the question as digits). Held-out: router 0, phrasing 6/11.

70B misses: main `rechazo_nacimientos_2024` (refused as "fuera_de_alcance" instead of reporting the 2022 coverage limit; a
refusal with no figure); held-out `p_vida_2024` ("¿Qué tan cara se puso la vida en 2024, punta a punta?") answered with the
Nov→Dec 2024 monthly change instead of the Dec–Dec change (figure correct for what it states, labelled with period and
series, but the wrong reading). The endpoint is not fully deterministic at temperature 0: in one earlier run with the same
prompts this item was refused instead; held-out was 12/13 in every 70B run.

8B: mostly over-refusal (Aug 2026 CPI as "forecast"; subway, tourism and oil questions as out of scope; the wage-vs-CPI
comparison as "advice"), plus annual-total plans on export series that cannot be summed (→ "no data"). One must-refuse question, "¿Cuántos pasajeros transportaron las aerolíneas en 2025?" (the snapshot
has flight counts, not airline passengers), was answered "En 2025 las aerolíneas transportaron 193.053,6 miles de
pasajeros": the figure is the real 2025 total of `302.3_TRANSP_PASSAJ_0_S_38` (subway + premetro passengers, Buenos Aires),
which the citation names, but the sentence attributes it to airlines. It passes the numeric grounding check (G5), which
verifies numbers, not labels: a limit of that metric, and a reason to ship the 70B model.

Method / fairness: prompts and validators were iterated on the **70B main** set only (real runs: 19 → 21 → 29 → 29 → 30,
then 30 in every later run). The held-out set was first run after prompts and validators were frozen; later reruns followed
only text post-processing fixes found in main/smoke output (repeated unit word, "%%") or re-verification; 12/13 each time.
A phrasing-prompt pass (don't copy dates from the question, "%" already in {variacion}, two shape examples) was tried on the
main set only: score unchanged 30/31 but phrasing use dropped 11 → 8 of 23, so it was reverted and not run on held-out.
The 8B ran once per set with the frozen prompts. Raw outputs contain answers and traces only (no headers, URLs or keys;
checked with `make leak-check`).
